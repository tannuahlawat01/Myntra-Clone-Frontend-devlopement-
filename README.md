# Myntra Landing Page Clone

A responsive **static clone of the Myntra homepage** built using **HTML5 and CSS3**.  
This project focuses on frontend layout design, Flexbox, and responsive UI practices.


## Tech Stack
- HTML5  
- CSS3  
- Flexbox  
- Utility-based CSS  


## Project Structure
index.html – Main HTML structure
style.css – Core styling and responsiveness
utils.css – Reusable utility classes (flex, spacing, alignment)

## Features
- Sticky navigation bar  
- Responsive layout for desktop and mobile  
- Flexbox-based page structure  
- Clean, reusable utility CSS classes  

## How to Run
Open `index.html` in any modern web browser.  
No installation or setup required.

## Purpose
Built to practice **frontend development fundamentals**, including:
- Page layout design  
- Responsive styling  
- CSS structuring and reusability
